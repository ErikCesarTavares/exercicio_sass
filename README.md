  O <b>EBAC Store</b> é um exercício da EBAC para uma aplicação web interativa que simula uma loja online com uma interface moderna e responsiva, onde os produtos são exibidos com imagens, descrições e links para mais detalhes. 🌟

## 🛠 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

- *HTML5* 🌐
- *CSS3* 🎨
- *Sass* 💅
- *JavaScript* 📜

---

## ✨ Projeto

A aplicação foi projetada para oferecer uma experiência simples e intuitiva para visualizar produtos em uma loja online. Ela inclui:

1. **Header Fixado**: Barra de navegação fixa no topo da página para facilitar o acesso ao menu.
2. **Lista de Produtos**: Exibe uma galeria de produtos com imagens e descrições detalhadas.
3. **Responsividade**: Design otimizado para dispositivos móveis, tablets e desktops.
4. **Estilização Moderna**: Utiliza um esquema de cores vibrante, com botões interativos e uma interface limpa e elegante.
